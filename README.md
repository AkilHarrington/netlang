# netlang

netlang is a simple language for writing Cisco network configs, made for
learners and engineers who want to get it right and understand why.

You describe the network you want. netlang checks it for mistakes, explains
each problem and how to fix it, and writes configs you can paste into your
devices. Later versions will apply changes to real devices safely.

Unlike netlab, which builds virtual labs and fills in the details for you,
netlang lets you decide every detail and checks your work.
